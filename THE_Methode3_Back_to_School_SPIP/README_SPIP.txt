THE Méthode 3 – Back to School
===============================

Le dossier est autonome : ne modifie pas son organisation interne.

MISE EN LIGNE CONSEILLÉE AVEC SPIP

1. Décompresse le ZIP sur ton ordinateur.
2. Avec ton logiciel FTP/SFTP (FileZilla par exemple), connecte-toi à l'hébergement de ton site.
3. À la racine du site, crée si besoin le dossier :
      jeux
4. Envoie le dossier complet :
      THE_Methode3_Back_to_School_SPIP
   dans :
      /jeux/
5. Le jeu devrait alors être accessible à une adresse de ce type :
      https://TON-SITE.FR/jeux/THE_Methode3_Back_to_School_SPIP/

INTÉGRATION DANS UN ARTICLE SPIP

Si ton SPIP autorise les iframes, insère dans l'article :

<iframe
  src="/jeux/THE_Methode3_Back_to_School_SPIP/index.html"
  width="100%"
  height="1000"
  style="border:0;border-radius:18px;"
  allow="autoplay"
  loading="lazy">
</iframe>

Si le jeu est coupé verticalement, augmente height="1000" à 1100 ou 1200.

IMPORTANT
- Le son vient des MP3 présents dans le fichier OpenBoard fourni.
- Les images utilisées viennent également de ce fichier OpenBoard.
- Le dossier fonctionne sans compte élève et sans installation.
- Les navigateurs mobiles peuvent exiger un premier clic de l'élève avant de lire un son automatiquement ; le bouton « Listen again » fonctionne alors.
